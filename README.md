Sistema Algorítmico para la Gestión de Préstamos de Libros en la Biblioteca de la UPN

Descripción:
Sistema desarrollado en C# mediante Formulario (Windows Forms) para gestionar datos de estudiantes y libros para los préstamos y devoluciones en la Biblioteca de la UPN.

Tecnologías:

- C#
- Windows Form (Formularios)
- GitHub
- Archivos de texto

Funcionalidades:

- Registro de estudiantes
- Consulta y búsqueda de registros.
- Eliminación de registros.
- Ordenamiento (Burbuja y selección) de estudiantes.
- Registro de libros
- Consulta y búsqueda de libros.
- Eliminación de registros.
- Ordenamiento (Burbuja y selección) de libros.
- Registro de préstamos.
- Eliminación de préstamos.
- Registro de devoluciones.
- Historial de devoluciones.
